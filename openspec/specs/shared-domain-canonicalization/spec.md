## Requirements
### Requirement: Single canonical overlay/audio-overlay ID generators

Overlay and audio-overlay IDs SHALL be generated by exactly one implementation each, exported from `src/shared/domain/project.ts` (`generateOverlayId`, `generateAudioOverlayId`). `src/renderer/app.ts` SHALL NOT define its own `generateOverlayId`/`generateAudioOverlayId` nor its own ID counters; it SHALL import and use the shared functions at all call sites.

#### Scenario: Renderer uses the shared generators
- **WHEN** the renderer creates a new overlay or audio overlay
- **THEN** the ID is produced by the shared generator and `app.ts` contains no local ID-generation function or counter

#### Scenario: ID format and uniqueness preserved
- **WHEN** many overlay IDs are generated in rapid succession
- **THEN** each matches the format `overlay-<timestamp>-<n>` (and `audio-overlay-<timestamp>-<n>` for audio), and all generated IDs are unique

### Requirement: Single canonical PiP-scale and export-audio-preset normalizers

`normalizePipScale` and `normalizeExportAudioPreset` SHALL exist only in `src/shared/domain/project.ts`. `src/renderer/app.ts` SHALL NOT define local copies; it SHALL import the shared functions. The shared `normalizeExportAudioPreset` returns the `ExportAudioPreset` union type, which all renderer call sites SHALL accept.

#### Scenario: Renderer imports the shared normalizers
- **WHEN** the renderer normalizes a PiP scale or an export-audio preset
- **THEN** it calls the shared implementation and `app.ts` defines neither function locally

#### Scenario: Normalization behavior unchanged
- **WHEN** `normalizePipScale` receives a non-finite or out-of-range value, or `normalizeExportAudioPreset` receives an unknown value
- **THEN** the results match the prior behavior (clamped to `[MIN_PIP_SCALE, MAX_PIP_SCALE]` / defaulted to the compressed preset), as covered by `tests/unit/project-domain.test.ts`

### Requirement: No duplicated domain logic remains in app.ts for the consolidated helpers

After this change, `src/renderer/app.ts` SHALL contain no local re-implementation of the consolidated helpers (overlay/audio-overlay ID generation, PiP-scale normalization, export-audio-preset normalization, `easeInOut`). Each SHALL be referenced via import from its canonical `src/shared/domain` module.

#### Scenario: Build proves all references resolve to shared modules
- **WHEN** `npm run typecheck` (`tsc --build`, strict, project references) runs
- **THEN** it succeeds with the renderer importing the consolidated helpers from `src/shared/domain/*` and no duplicate definitions remaining
